## Defect R1-01 — Hero primary button color contrast

**Observed via theme tokens and published block markup**:

- Before: button foreground `white` (`#FFFFFF`), background `vivid-cyan-blue` (`#0693E3`).
- Calculated contrast: **3.34:1** — FAIL for ordinary-size text against WCAG 2.2 AA 1.4.3 (minimum 4.5:1). Standard: https://www.w3.org/TR/WCAG22/#contrast-minimum
- Correction: Changed only the first hero Gutenberg `core/button` foreground to existing site theme token `theme-5` (`#000000`), updated corresponding `has-theme-5-color` class. Kept the cyan background, URL, label, hero block, and all other sections unchanged.
- New calculated contrast: **6.29:1** — PASS at block color-configuration level (browser screenshot remains UNKNOWN).
- Write method: `page-sections.replace`, page 16 / section index 0, matching `expected_modified`, `expected_content_hash`, and `expected_block_hash` before write.
- WordPress returned no `_content_warnings` on mutation.
