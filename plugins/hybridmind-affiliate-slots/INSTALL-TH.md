# ติดตั้งและตั้งค่าฉบับย่อ (0.3.0)

ไฟล์นี้เป็นชุดส่งมอบสำหรับตรวจและติดตั้งเอง ยังไม่มีการติดตั้งหรือแก้ไขเว็บไซต์จริง

1. สำรองค่าปลั๊กอิน Affiliate Slots ปัจจุบันไว้ก่อน
2. ใน WordPress Admin ไปที่ **ปลั๊กอิน → เพิ่มปลั๊กอิน → อัปโหลดปลั๊กอิน** แล้วเลือก ZIP รุ่น 0.3.0 เพื่อแทนที่ไฟล์เดิม โดยอย่าลบข้อมูลปลั๊กอินหรือรีเซ็ตตัวเลือก
3. ไปที่ **ตั้งค่า → Affiliate Slots** ตัวเลือกวางโฆษณาอัตโนมัติปิดไว้เป็นค่าเริ่มต้น การอัปเดตปลั๊กอินไม่เปิดตำแหน่งเพิ่ม
4. เลือกเฉพาะตำแหน่งที่ต้องการ แล้วกดบันทึก การเปลี่ยนตำแหน่งจะล้างการตรวจทานและการอนุมัติเดิม
5. ตรวจข้อมูลและตัวอย่างส่วนตัว แล้วเจ้าของเว็บต้องอนุมัติรุ่นข้อมูลและตำแหน่งปัจจุบันอย่างชัดเจน โฆษณาจะแสดงได้เมื่อสินค้า ช่อง และภาพที่ยืนยันสิทธิ์เปิดใช้งานครบ

หน้าแรกวางหลัง Featured ได้เฉพาะเมื่อบล็อก HTML เดียวมีขอบเขต Hero และ `#latest` ตรงตามที่ตรวจพบ หากโครงสร้างเปลี่ยน ตัวกรองจะไม่แทรกเนื้อหา ให้ใช้บล็อก Shortcode `[hm_affiliate_slot id="home_after_feature"]` หลัง Featured และก่อน `#latest` หลังตรวจตำแหน่งในตัวแก้ไขแล้ว

การย้อนกลับให้แทนไฟล์ปลั๊กอินด้วยรุ่นก่อนหน้าและเก็บตัวเลือก `hm_affiliate_slots_v1`, `hm_affiliate_auto_placements_v1` พร้อมตัวเลือกสำรองไว้ รุ่นเก่าจะไม่รู้จักตำแหน่งอัตโนมัติ และอาจปิดการแสดงผลไว้จนกว่าเจ้าของจะตรวจทานและอนุมัติใหม่ในรุ่นนั้น ห้ามลบหรือล้างค่าปลั๊กอินเพื่อย้อนกลับ
