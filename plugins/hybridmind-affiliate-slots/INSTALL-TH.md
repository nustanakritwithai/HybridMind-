# ติดตั้งและตั้งค่าฉบับย่อ (0.3.2)

ไฟล์นี้เป็นชุดส่งมอบสำหรับตรวจและติดตั้งเอง ยังไม่มีการติดตั้งหรือแก้ไขเว็บไซต์จริง

1. สำรองค่าปลั๊กอิน Affiliate Slots ปัจจุบันไว้ก่อน
2. ใน WordPress Admin ไปที่ **ปลั๊กอิน → เพิ่มปลั๊กอิน → อัปโหลดปลั๊กอิน** แล้วเลือก ZIP รุ่น 0.3.2 เพื่อแทนที่ไฟล์เดิม โดยอย่าลบข้อมูลปลั๊กอินหรือรีเซ็ตตัวเลือก
3. ไปที่ **ตั้งค่า → Affiliate Slots** ตัวเลือกวางโฆษณาอัตโนมัติปิดไว้เป็นค่าเริ่มต้น การอัปเดตปลั๊กอินไม่เปิดตำแหน่งเพิ่ม
4. เลือกเฉพาะตำแหน่งที่ต้องการ แล้วกดบันทึก การเปลี่ยนตำแหน่งจะล้างการตรวจทานและการอนุมัติเดิม
5. ตรวจข้อมูลและตัวอย่างส่วนตัว แล้วเจ้าของเว็บต้องอนุมัติรุ่นข้อมูลและตำแหน่งปัจจุบันอย่างชัดเจน โฆษณาจะแสดงได้เมื่อสินค้า ช่อง และภาพที่ยืนยันสิทธิ์เปิดใช้งานครบ

หน้าแรกวางหลัง Featured ได้เฉพาะเมื่อบล็อก HTML เดียวมีขอบเขต Hero และ `#latest` ตรงตามที่ตรวจพบ หากโครงสร้างเปลี่ยน ตัวกรองจะไม่แทรกเนื้อหา ให้ใช้บล็อก Shortcode `[hm_affiliate_slot id="home_after_feature"]` หลัง Featured และก่อน `#latest` หลังตรวจตำแหน่งในตัวแก้ไขแล้ว

การย้อนกลับให้แทนไฟล์ปลั๊กอินด้วยรุ่นก่อนหน้าและเก็บตัวเลือก `hm_affiliate_slots_v1`, `hm_affiliate_auto_placements_v1` พร้อมตัวเลือกสำรองไว้ รุ่นเก่าจะไม่รู้จักตำแหน่งอัตโนมัติ และอาจปิดการแสดงผลไว้จนกว่าเจ้าของจะตรวจทานและอนุมัติใหม่ในรุ่นนั้น ห้ามลบหรือล้างค่าปลั๊กอินเพื่อย้อนกลับ

## 0.3.2: ตำแหน่งกึ่งกลางบทความ

ตำแหน่งกึ่งกลางบทความ (Article midpoint) ปิดไว้เป็นค่าเริ่มต้น ผู้ดูแลเลือกตำแหน่งบทความได้ไม่เกินสองตำแหน่ง ตำแหน่งกึ่งกลางใช้รายการสินค้าจากช่อง `article_after_intro` เดิม จึงไม่เพิ่มช่องสินค้าและไม่เปลี่ยน schema ของ config รุ่น 1

ระบบนับย่อหน้าระดับบนสุดและภายใน Gutenberg `core/group` เท่านั้น โดยรองรับการซ้อนกันได้ไม่เกิน 8 ชั้น และแทรกเฉพาะขอบเขตระหว่างย่อหน้าที่ตรวจสอบได้ใน container เดียวกัน ส่วน `core/html`, columns, embeds, tables และ block ชนิดอื่นยังคงเป็นข้อมูลทึบ หากหาขอบเขตที่ปลอดภัยไม่ได้ ระบบจะไม่แทรกโฆษณา

การเปิดตำแหน่งใหม่ต้องผ่านการตรวจทานและอนุมัติของเจ้าของเว็บ ตำแหน่งบทความเปลี่ยนแล้วระบบจะล้าง review และ approval เดิม การอัปเดตนี้ไม่มีการย้ายฐานข้อมูล ให้คง option สินค้าและตำแหน่งเดิมไว้เมื่อติดตั้งหรือ rollback รุ่น 0.3.1 ไม่รู้จักตำแหน่งกึ่งกลางและจะปิดตำแหน่งอัตโนมัติเมื่อพบ key ใหม่; เมื่อติดตั้ง 0.3.2 กลับ สามารถอ่านค่าที่เก็บไว้ต่อได้
